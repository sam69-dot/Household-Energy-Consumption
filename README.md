# Household Energy Consumption Analysis & Prediction

## Project Overview

This project explores household energy consumption patterns and applies machine learning techniques to predict energy consumption.

Using R programming, the project investigates relationships between energy-related variables and evaluates the performance of Support Vector Machine (SVM) and Decision Tree models.

The objective is to understand consumption patterns, prepare the dataset for modelling, and compare predictive model performance.

## Objectives

- Explore and understand household energy consumption data.
- Perform data preprocessing and handle missing values.
- Identify relationships between variables through exploratory data analysis.
- Develop machine learning models using SVM and Decision Tree algorithms.
- Evaluate and compare model performance.

## Technologies & Libraries

- **Programming Language:** R
- **Machine Learning:** Support Vector Machine (SVM), C5.0 Decision Tree
- **Data Processing:** R data manipulation and preprocessing
- **Visualisation:** R plotting libraries
- **Evaluation:** Confusion Matrix and Accuracy

## Methodology

### 1. Data Preparation

- Loaded the household energy consumption dataset.
- Examined missing values and duplicate records.
- Prepared the data for exploratory analysis and modelling.

### 2. Exploratory Data Analysis

- Investigated relationships between variables.
- Examined correlations.
- Used visualisations to understand patterns in the dataset.

### 3. Machine Learning Models

**Support Vector Machine (SVM)**

Applied SVM using linear and radial basis function (RBF) kernels to explore different classification approaches.

**Decision Tree**

Implemented a C5.0 Decision Tree model to examine the predictive relationships within the dataset.

### 4. Model Evaluation

Model performance was assessed using confusion matrices and accuracy metrics.
